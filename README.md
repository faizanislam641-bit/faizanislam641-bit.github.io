## GitHub Pages
1. Create a GitHub repository. For a personal site, `YOURUSERNAME.github.io` is a convenient name.
2. Upload the contents of this folder to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site. After it is published, VS Code and your PC do not need to stay on.

The site is self-contained except for the external links to GitHub/Fiverr/WhatsApp/email.
